# 🌍 TripMate – AI-Powered Collaborative Trip Planner

> **Plan Smart. Travel Together. Stay Safe.**

TripMate is a modern AI-powered travel planning platform that helps users organize solo or group trips with ease. The application combines intelligent trip planning, real-time collaboration, emergency assistance, and offline accessibility to make every journey safer and more enjoyable.

## ✨ Features

* 🤖 AI-powered trip planning using **Google Gemini API**
* 🗺️ Interactive map integration for navigation and nearby services
* 👥 Create or join solo and group trips
* 💬 Real-time group chat and collaboration
* 💰 Shared expense tracking and trip budgeting
* 🆘 Emergency support with first-aid guides and SOS information
* 📶 Offline access to essential travel information using PWA
* 🔐 Secure authentication with email verification and session management
* 🪪 User identity verification for trusted travel communities
* 🔔 Email notifications and trip reminders
